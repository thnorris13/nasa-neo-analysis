# NASA Near-Earth Object (NEO) Analysis

A collection of computational astrophysics reviews, telemetry datasets, and close approach analyses tracking Near-Earth Objects.

## Contents
- **October 2026 Monthly Review & Synthesis**: High-level overview and telemetry evaluation for October.
- **NEO Telemetry & Close Approach Analysis**: Detailed transit and close approach data tracking.

## Tools & Environment
- **Language**: Python (Jupyter / Google Colab)
- **Libraries**: Pandas, Matplotlib, Seaborn, Astropy
- **Data Source**: NASA Near-Earth Object telemetry
