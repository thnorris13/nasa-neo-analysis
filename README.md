# NASA Near-Earth Object (NEO) Analysis

A collection of computational astrophysics reviews, telemetry datasets, and close approach analyses tracking Near-Earth Objects.

## Contents
- **October 2026 Monthly Review & Synthesis**: High-level overview and telemetry evaluation for October (`October_2026_NASA_Near_Earth_Object_(NEO)_Monthly_Review_&_Synthesis.ipynb`).
- **NEO Telemetry & Close Approach Analysis**: Detailed transit and close approach data tracking (`NASA_Near_Earth_Object_(NEO)_Telemetry_&_Close_Approach_Analysis.ipynb`).
- **November 2026 Week 1 Telemetry Analysis (Nov 1–7, 2026)**: Weekly NASA NeoWs API feed ingestion and close-approach evaluation (`NASA_NEO_Analysis_Nov_01_07_2026.ipynb`).
- **November 2026 Week 2 Telemetry Analysis (Nov 8–15, 2026)**: Weekly NASA NeoWs API telemetry pipeline covering 43 NEOs and 5 PHAs, paired with the archived CSV dataset (`NASA_Near_Earth_Object_Telemetry_Analysis_—_Week_2_(November_8–15,_2026).ipynb` and `neo_telemetry_2026_11_08_to_15.csv`).

## Tools & Environment
- **Language**: Python (Jupyter / Google Colab)
- **Libraries**: Pandas, Matplotlib, Seaborn, Astropy, Requests
- **Data Source**: NASA Near-Earth Object Web Service (NeoWs) API
